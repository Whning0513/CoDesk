# Workspace Assembly Lite v1

A 在真实文件管理器中把一份检查记录从 incoming 移到交付目录，保留字节内容，并将文件名和文件内的检查标签交接给 B。B 可以先阅读 Writer 草稿；收到 A 的已保存产物和消息后，通过 GUI 核对交付文件，再完成一页报告中的附件句子。

交付为 `inspection_note.txt` 与 `handoff_report.odt`。评分侧分别检查移动前后的字节一致、原位置不再有文件、Writer 报告结构及标签/文件名正确。真实协作还需从文件管理器、消息、修订同步和 GUI 读取轨迹判定。原版四附件任务不改动。

v1.0.1：B 若完成初步查看后仍缺 A 的已保存交付，可发消息并结束当前回合；协调器等待公开消息与文件版本后恢复同一对话，等待时不消耗 B 的模型执行时间。Shared 和 Isolated 使用同一机制。
