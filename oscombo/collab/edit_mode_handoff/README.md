# EDIT-1 Lite v1

This case tests LibreOffice Writer's Insert/Overwrite editing mode as a shared session state. It is a compact release-notice workflow: one role inserts a release-ready marker before a fixed risk phrase; the other updates a fixed-width reviewer code. A's stale insertion plan can overwrite the phrase after B changes the mode to OVR.

The public fixture is generated by `fixtures.build_fixture`. Evaluator-only Gold and the deliberate overwrite-signature negative control are separate. The semantic Oracle reads the saved FODT text and compares complete required lines; it does not accept a nonempty evidence field or a hand-entered revision claim as proof.

`TASK_CARD_ZH.md` contains the full actor contract and topology rules. `scripts/run_edit_mode_handoff_guest_control.py` runs real-Guest scripted Isolated and Shared controls on Native QEMU; it is a mechanism/control adapter, not the model-agent production adapter. The successful scripted control IDs and evidence paths are listed in `IMPLEMENTATION_REPORT_ZH.md`. There are no model results. Promotion requires message/revision provenance from the production bridge and then a valid Isolated model pass before any Shared model arms.

Run the offline controls:

```bash
python - <<'PY'
from pathlib import Path
from tempfile import TemporaryDirectory
from oscombo.collab.edit_mode_handoff.fixtures import build_fixture
from oscombo.collab.edit_mode_handoff.oracle import evaluate_controls
with TemporaryDirectory() as root:
    build_fixture(Path(root))
    print(evaluate_controls(Path(root)))
PY
```
