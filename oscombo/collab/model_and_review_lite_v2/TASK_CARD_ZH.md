# Model-and-Review Lite v2（CDD-MAR-LITE-002）

任务：将灯罩在 Blender 中水平等比例放大，并对**实际保存的项目**做安全间距审查。v2 为独立版本，v1 文件和历史实验不变。

A 的工程已打开且灯罩被选中。A 在三维视口对灯罩的 X/Y 维度按 1.25 缩放、保持高度和其他对象不变，保存并发布；给 B 的消息只说明修订就绪。角色提示给出标准 GUI 快捷操作，以减少 Blender 数值框编辑的无关负担。

B 可以先查看初始场景或报告，但最终尺寸和缩放比例不在 B 的提示或公开说明中。B 在 A 保存后通过 Blender GUI 打开或 Revert 已交付版本，读取灯罩 X 宽；依据公开的灯泡宽 0.50 m 和径向净空公式计算实际净空，写入宽度、净空及 0.40 m 阈值判定，保存并发布。B 不得编辑 A 的项目。消息、附件、修订路径及已保存原始文件在两种拓扑等价可见。

Gold 与 Oracle 仅在评分侧。独立 Oracle 重新打开真实 `.blend`，验证灯罩 X/Y、高度、网格、材质和位置，以及受保护对象；再比较 B 的文本、净空及结论与实际保存的场景。Oracle PASS 不单独证明 GUI 阅读：人工结合 B 的 Blender 截图、读取动作和 A 的修订/消息时序审核协作。若 A 把结果写入消息或 B 在交付之前从其他位置取得答案，单独记录，不将其当作有效的场景阅读交接。

Shared 为同一桌面、无输入锁；Isolated 为两个桌面和同等保存版本桥。Shared+Lock 仅串行化一次 GUI 输入调用，不覆盖观察到执行之间的焦点；三种条件使用同一模型、角色指令、Fixture、预算和 Oracle。先进行真实 GUI 正负控、保存与重开、版本桥审计和小预算 Pilot，再冻结三臂。
