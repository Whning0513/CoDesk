# Workspace Assembly Lite v1.0.2

A 在真实文件管理器中先把一份检查记录从 incoming 移到交付目录，保留字节内容；再用 GUI 打开交付后的文件，读取检查标签，并将文件名和标签交接给 B。B 可以先阅读 Writer 草稿；收到 A 的已保存产物和消息后，必须自己通过 GUI 打开交付文件、核对标签，再完成一页报告中的附件句子。A 的消息不能替代 B 的文件核验。

交付为 `inspection_note.txt` 与 `handoff_report.odt`。评分侧分别检查移动前后的字节一致、原位置不再有文件、Writer 报告结构及标签/文件名正确。真实协作还需从文件管理器、消息、修订同步和 GUI 读取轨迹判定。原版四附件任务不改动。

v1.0.2：保留 v1.0.1 的 B 等待/唤醒机制；将 Files 初始窗口最大化，并明确 A 先移动再读取已交付文件，减少读完源文件后切回小 Files 窗口的无关难度。两种桌面拓扑采用完全相同的布局和角色指令。原 v1.0.1 文件与历史实验不改动。
